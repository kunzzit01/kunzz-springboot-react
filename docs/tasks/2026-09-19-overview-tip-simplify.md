## 用户反馈（截图）

悬浮提示现在是：

```
各系统单价：J1 2222 · J3 0
最近改价（中央）: 19/09/2026 RM32.00（Soon）
要修改：切到中央/J1/J2/J3 页面
```

要求：
1. **不要「最近改价（中央）」** —— 那是中央的改价记录，对只有 J1/J3 权限的人属于别家分店的信息
2. **不要「要修改：…」** 这一行
3. **数值要带 RM 单位**

## 做法

**后端**：`joinBySystem(..., withUnit)` 加一个"带单位"开关 → 总览额外给一份
`price_by_system_tip`（`J1 RM 2222 · J3 RM 0`）；原来的 `price_by_system` 保持不带单位
（表格单元格用，列头已经写了 单价(RM)，短一点不容易被截断）。

**前端**：
- 悬浮提示只留一行：`各系统单价：<带 RM 的文本>`（没有最近改价、没有"要修改"）
- 冰箱分类的悬浮同样去掉"要修改"那行，只留 `各系统冰箱分类：…`
- **系统页的单价悬浮保持不变**（那里显示的是"当前系统自己的"最近改价 + 改价人，
  是用户上一轮特意要的；总览才会串到中央的记录）

## 本地验证（真后端 + 真实浏览器，J1+J2 权限的账号）

| 位置 | 单元格 | 悬浮提示 |

| 总览 · 冰箱分类 | `J1 ICE BOX 1 · J2 -` | `各系统冰箱分类：J1 ICE BOX 1 · J2 -` ✓（去掉"要修改"） |
