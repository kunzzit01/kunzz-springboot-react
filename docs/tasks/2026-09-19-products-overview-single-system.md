## 问题（用户报）

"货品种类只有一间分店权限就无需展示总览"（截图：J1 账号的系统下拉里还有「总览」）

「总览」是**跨系统只读视图**：单价格子显示的是 4 套系统的价（`中央 1111 · J1 2222 · J2 0 · J3 0`）。
只勾了 J1 的账号能打开它，等于能看到别家分店的单价 —— 既没必要，也是数据外泄。

## 改法（StockProducts.tsx）

1. 新增「权限是否配置过」标记（`allowedSystems=[]` 既可能是"没配置"也可能是"配置了但全关"，原来分不清）
2. `showOverview = 没配置权限 || 有 2 个以上系统`：
   - 只勾一间分店/只勾中央 → 下拉里不出现「总览」，默认落到自己有权限的那间
   - 有 2 个及以上 → 保留「总览」（跨店比对还有用，跟现在一致）
3. 权限全关（配置过、一个没勾）→ 整页显示「无权限访问」，并且**不取数**
4. 顺带修一个被这次改动"暴露"出来的竞态（见下）

## 顺带修的越权竞态（重要）

原来页面**在权限返回之前就先拉了一次列表**（按"无限制"拉全量 611 条），权限到达后切成 J1 再拉一次（110 条）。
实测两个响应会打架 —— 总览那份 611 条更大更慢，**后到**，把 J1 的 110 条覆盖回去：

```
?systemAssign=      start 1878/1883  end 2430/2541   ← 611 条，最后落地
?systemAssign=j1    start 2014/2015  end 2064/2182   ← 110 条，被覆盖
→ 页面标题写着 J1，列表却是全部 611 条货品（含别家分店）
```

两处修：

- **权限就绪前不取数**（`permsSettled`，成功失败都算就绪）→ 不再多拉那一次全量
- **只认最后一次请求的结果**（`loadSeq` 序号，旧响应回来直接丢弃）→ 切系统/连续操作也不会被旧数据盖回
